# \## Objetivo

# 

# Implementar melhorias apenas na validação manual.

# 

# \## Escopo desta tarefa

# 

# Implementar uma lista lateral de objetos detectados.

# 

# \## Requisitos

# 

# \- Exibir todos os objetos detectados.

# \- Exibir classe.

# \- Exibir ID.

# \- Seleção sincronizada:

# &#x20;   - clique na lista seleciona a caixa.

# &#x20;   - clique na caixa seleciona a lista.

# \- Destacar objeto selecionado.

# \- Permitir alterar a classe.

# \- Permitir excluir.

# \- Botão Salvar.

# \- Não quebrar nenhuma funcionalidade existente.

# 

# \## Não pode

# 

# \- Alterar backend.

# \- Alterar banco.

# \- Alterar API.

# \- Alterar docker.

# \- Alterar autenticação.

# \- Alterar rotas.
